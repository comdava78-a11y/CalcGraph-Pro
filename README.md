# 🧮 CalcGraph Pro

Инженерный калькулятор + графики функций. Работает прямо в браузере.

## Что умеет

- **Калькулятор**: sin, cos, tan, log, ln, √, xʸ, π, e, факториал, проценты
- **Графики**: стройте функции от x, несколько графиков сразу, скачивайте PNG/SVG
- **Тёмная/светлая тема**, авто по времени
- **История вычислений**, сохраняется
- **Горячие клавиши**, голосовой ввод
- Работает на телефоне и компьютере

## Как запустить

Откройте `index.html` в браузере. Всё.
